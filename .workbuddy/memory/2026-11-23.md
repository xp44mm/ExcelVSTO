## 修复：DisplayDefaults.fs 编译错误（用户提供 VS 报错）

- FS0039：Office15 PIA 的 Window 接口没有 DisplayPageBreaks（该属性属 Worksheet）。改用 ws.DisplayPageBreaks <- false。
- FS0001×2：Window.GridlineColorIndex 在本 PIA 是 XlColorIndex 枚举类型，不是 obj；去掉 box，直接赋 XlColorIndex.xlColorIndexAutomatic。
- 经验：本 PIA 中「显示分页符」是工作表级属性（ws），不是窗口级；GridlineColorIndex 强类型枚举，勿用 box。与 Window 上 DisplayHeadings/Formulas/RightToLeft/Zeros/Outline/Gridlines 这些 bool 属性不同。
- 文件仍 BOM+CRLF 末尾 CRLF。等待用户重新生成验证。
