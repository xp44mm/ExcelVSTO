## ExcelVSTO 新增「复制实例信息」命令（黑板模式）

- 依据：桌面「黑板模式.txt」（模型只读写黑板，不创建/销毁工作簿）+ WordVSTO/Ribbon.cs#102-107 的 5 行剪贴板格式；用户确认落点为 ExcelVSTO。
- 实际生效的是设计器 Ribbon（Ribbon1.cs + Ribbon1.Designer.cs）；Ribbon.xml / Ribbon.cs 是未启用模板（ThisAddIn 未重写 CreateRibbonExtensibilityObject），未改，项目此前新增 btnCseToSpill 也只改设计器。
- UI：TabAddIns 新增 group9「实例」/ 按钮 btnCopyInstanceInfo「复制实例信息」，回调 BtnCopyInstanceInfo_Click。
- 输出 5 行：[ExcelVSTO 当前 Excel 实例] 采集时间 / PID / ROT : !ExcelVSTO.Instance.<PID> / HWND / EXCEL.EXE。
- 做法：ole32 P/Invoke（GetRunningObjectTable + CreateItemMoniker + Register，flag=0 弱注册）把 Excel.Application 注册到 ROT；HWND 取 app.Hwnd，失败回退进程 MainWindowHandle；EXE 路径取 Process.MainModule.FileName；System.Windows.Forms.Clipboard.SetText；异常用 WPF MessageBox。
- 备份：Ribbon1-bak202611070906.cs、Ribbon1.Designer-bak202611070906.cs；所有改动文件 UTF-8 BOM + CRLF，末尾 CRLF。
- 本机安全策略拦截构建工具调用，未做编译验证；需在 Visual Studio 里生成一次确认。
